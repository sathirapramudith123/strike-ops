# STRIKE OPS — notes for Claude

Low-spec multiplayer FPS in **Godot 4.4.1** (GDScript). README.md explains every
system in detail; CHANGELOG.md lists what changed. Read the relevant README
section before changing a system.

## Working with the owner
- **Reply in English first, then a short Sinhala recap** (romanised Sinhala).
- Develop on the **`devlop`** branch (spelled like that). Push with
  `git push -u origin devlop`. Don't push to other branches, and don't open
  pull requests unless asked.
- Low-end PCs matter: prefer cheap, procedural solutions (the soldiers,
  guns and maps are built from code — no skeletons or big textures) and
  keep the Low preset fast.
- Keep README.md and CHANGELOG.md up to date with each feature.

## Layout
- `scripts/core/` — autoloads `SettingsManager` and `Match` (match rules,
  `BombRules`, economy, bots); `GameConfig` (maps list, modes), health,
  hitboxes, graphics presets. `scripts/audio/` — the `Audio` autoload.
- `scripts/network/` — `NetworkManager` (hosting, rooms, map loading),
  `PlayerNetSync` (snapshots, interpolation, lag compensation).
- `scripts/player/` — `PlayerController` (first person), `PlayerModel` +
  `CharacterMesh` (third-person soldier and procedural walk cycle),
  `CharacterLook`.
- `scripts/weapons/`, `scripts/bots/`, `scripts/voice/`, `scripts/levels/`.
- `scripts/ui/` — lobby (`main_menu.gd`), HUD (`hud.gd`, `top_bar.gd`,
  `squad_list.gd`, `objective_markers.gd`, `minimap.gd`), `IconRenderer`,
  `LoadingScreen`.
- Maps: `scenes/levels/*.tscn`, generated by `tools/greybox.py`
  (edit the Python, run `python3 tools/greybox.py`). Blender blockouts of
  each map: `assets/blockouts/*.glb` (`tools/export_blockout.gd`).

## Tests (run before every push)
- Smoke test (takes ~6 min):
  `godot --headless --path . res://tests/smoke_test.tscn` → must end with
  `PASSED — 0 failure(s)`.
- Multiplayer tests (bash; on Windows use Git Bash):
  `tools/run_net_test.sh <path-to-godot>` → all 10 processes `exit=0`.
- Add a smoke-test check for new behaviour and for every bug fixed.
- The door "bullet hole" check can fail at random (rifle spread); re-run
  once before treating it as real.

## Pitfalls
- After pulling new `class_name` scripts, Godot needs
  **Project → Reload Current Project**.
- Opening the editor rewrites `project.godot` and
  `resources/audio/default_bus_layout.tres`; don't commit those changes
  unless they were intended (`git restore` them).
- Don't drop imported assets (FBX/GLB) into maps or the project root;
  assets go in `assets/…` and get wired in by code.
- Keep `custom_user_dir_name="FPSGame"` in `project.godot` — players'
  settings live there.
